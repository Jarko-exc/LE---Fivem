# FIELDNOTE
Česká příručka pro LSPD a LSSD v GTA V RP. Statický web bez externích závislostí.

Spuštění: `npm start`, port 3000. Kontrola JavaScriptu: `npm run check`.
Lze také otevřít index.html přímo nebo nasadit tři soubory index.html, style.css a app.js na statický hosting.

Obsah je v app.js. Nejednoznačné kódy jsou označené k ověření u vedení serveru. Právní texty jsou herní podklady, nikoliv skutečné právní rady. Výbava se ukládá pouze v místním prohlížeči. Web neobsahuje evidenci členů ani přihlášky.
